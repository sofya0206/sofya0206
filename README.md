### How I work

- **AI as a teammate, not an autopilot.** I build with coding agents, and I write the rules, architecture decisions and tests that keep their output correct.
- **Grounded AI.** In Agora our assistant uses the language model only to read the request and write the reply. The facts come only from the database, and scoring is deterministic.
- **Ship, then measure.** Both products are live. I learn from users, not from tutorials.
